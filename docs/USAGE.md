# ComUI 使用说明

> 机器视觉/3D 扫描显示平台（Avalonia 插件化，Win/Ubuntu）。本页面向使用者；架构与二次开发见 [ARCHITECTURE.md](ARCHITECTURE.md)，交互规则与组件复用见 [CONVENTIONS.md](CONVENTIONS.md)，历史坑位检索见 [BUGS.md](BUGS.md)。

## 启动

- Windows：双击 `start.bat`（编译+启动）或直接运行 `src\ComUI.Host\bin\Debug\net8.0\ComUI.Host.exe`
- Ubuntu：`./start.sh`
- 单实例保护：重复启动会激活已有窗口。**F5** = 重载全部插件（开发期热更新）。

## 界面布局

左侧活动栏（图标=侧边栏开关）｜侧边栏（面板/算法配方/数据树/总线监视/算子库）｜中间**分屏标签区**（可拆分多格/浮动独立窗口）｜右侧属性面板（当前面板参数）｜底部日志。

「🧩 面板」列表只显示**窗口面板**（点击打开/聚焦标签页）；数据树、总线监视、算子库等侧边栏工具不在此列——用活动栏图标切换。**按住面板行拖动可给栏目排序**（拖到目标行的上半=插到其前、下半=插到其后），顺序重启保持。

**分屏标签区**：标签可**按住左右拖动排序**——拖到本组标签条上松手=按落点位置插队（插入线指示落点）；拖到另一格的标签条上=把标签移过去插到那个位置；拖到格子的左/右/上/下边缘=拆分新格；拖出主窗=浮动独立窗口。

**快照对比**：2D/3D 工作台工具栏「📷 快照」把当前画面冻结成**只读快照标签页**——2D 保留适配窗口/1:1/缩放/平移/取色，3D 保留旋转/缩放/平移/投影切换（并继承快照那一刻的视角），无拾取/框选/发布等加工功能，也不随总线数据更新。想并排对比：给工作台和快照各拖一格分屏即可；快照不进会话，重启自动丢弃。

欢迎页是普通标签页，可随时 ✕ 关闭；找回来走菜单「视图 → 欢迎页」。

## 算法流水线（核心插件）

1. 左侧 🧰 算子库：**拖到画布**创建节点（或单击加到中心）；顶部搜索框过滤；分组栏目头可拖拽排序。
2. 工具栏：**▶ 运行**（手动执行一次）｜**■ 停止**（取消正在执行的流水线）｜**自动运行**（默认**关**——开启后改参数/连线自动重跑）｜保存算法｜清空。运行中「▶ 运行中…」按钮变**绿**、「■ 停止」可用；空闲时运行钮灰、停止钮置灰禁用——运行状态一眼可辨。瞬间完成的流水线绿态也会保持约 0.6 秒（最短可见时长），反馈不会一闪而过。 **分组栏目头按住拖动可排序**（落点横线指示，上/下半=插其前/后），原地点击=折叠/展开；顺序存 `config/op_order.json`，重启保持。
3. 从输出端口拉线到输入端口连接；**一个输出可分叉连多个输入**（数据流分发）；拖已连输入=换源（新线替换旧线）。
3. 节点参数（滑杆/下拉/文本）运行时可改，防抖 0.5s 自动重跑。
5. 「保存算法」把当前编排存入左侧 ⚡「算法配方」侧边栏的「流水线算法」区。
6. ⚡算法配方侧边栏：**单击**算法 = 选中并打开（已打开则直接跳转到该页面）；**双击**算法名 = 行内重命名（**Enter 确认 / Esc 取消**，与节点卡片、点云树一致）；行右端小锁 = 锁定状态（**绿色开锁=可编辑，灰色闭锁=锁定**，所有行等宽、锁对齐一列），点击切换——锁定的算法以只读打开（禁止改参数/连线/节点），「保存」变为「复制副本」。
6. 文件基础操作：单击选中算法后 **Ctrl+C 复制、Ctrl+V 粘贴为「原名 副本」**（解锁可编辑）、**Del 删除**（仅解锁状态——锁定的算法先解锁或删副本）；打开的页面 **Ctrl+S 直接保存回原文件**（新页面弹另存对话框）；所有行内改名框统一 Enter=确认、Esc=取消。
7. **退出自动保存布局**：关闭应用时记住窗口大小、分屏结构、打开的算法页与侧边栏，下次启动自动恢复（算法页按文件重新加载并自动执行）；「视图 → 默认布局」一键回到初始状态。
8. 标签页可**浮动**：拖出主窗边界、标签右键「浮动窗口」或 **Ctrl+Alt+F** = 独立窗口显示（随主窗最小化/关闭）；浮动窗工具条「⇲ 固定到主窗」拖回。**浮动态和窗口位置/大小会保存在会话里**——重启后原位恢复。
9. 标签页可**拖拽**：拖到另一格中心=移入该组；拖到格子边缘（左右上下 28% 区域）=朝该方向拆分新格；**Ctrl+Alt+方向** = 拆分当前激活标签（键盘等价）；Esc 取消拖拽；标签右键菜单同款操作。
10. 画布节点卡片：**双击头部** = 行内改名；**单击选中（蓝框）→ Del 删除**（右键菜单删除同效）；**Ctrl+C 复制 / Ctrl+V 粘贴副本**（参数/标题/变量名随行，连续粘贴阶梯偏移）。
11. 算子库「**输出预览**」卡片带「名字」框（**变量名**）：默认自动填输入源节点名（可改，改动随算法保存）；「→ 2D/3D 工作台」导入时按变量名命名，数据树里按此名显示。
12. 示例图（默认加载）：关联高度图 → 发布图像+点云；立方体 → 第二条点云。
13. 算子库「**输出预览**」栏目：**2D 预览 / 3D 预览** 卡片，接到任意图像/点云输出即可在流水线里直接看到结果——2D 卡片内嵌缩略图，3D 卡片内嵌迷你 3D 视图（**左键拖拽旋转**）；卡片上「→ 2D 工作台 / → 3D 工作台」一键把当前预览导入对应工作台（自动切换到该标签页；点云按原 Id 更新工作台实体，无名点云以「预览点云」导入）。

## 2D 图像查看器

| 操作 | 效果 |
|---|---|
| 滚轮 | 以光标为中心缩放 |
| 工具栏「＋ / －」 | 以视图中心放大/缩小（1.25× 步进） |
| 左键拖拽 | 平移 |
| 工具栏「适配窗口 / 1:1」 | 取景 |
| **≥100% 放大** | 最近邻采样——像素级检视，每图像像素呈锐利方块（缩小自动切 mipmap 抗摩尔纹），最高 64× |
| 光标悬停 | 状态栏显示像素坐标 + BGRA + hex |
| **Ctrl+左键拖拽** | 框选 ROI（青色常显，随缩放平移联动），发布 `sel/roi2d` |
| Esc | 清除 ROI 与高亮 |

## 3D 点云查看器

| 操作 | 效果 |
|---|---|
| 左键拖拽 | 旋转（四元数翻滚，可过极点） |
| 右键拖拽 | 平移（grab：拖右云右、拖下云下） |
| 滚轮 | 缩放 |
| **Ctrl+左键单击** | 拾取最近点（洋红十字标 + 属性面板坐标），发布 `sel/point3d`（带归一化 uv） |
| **Ctrl+左键拖拽** | 框选（洋红高亮 + 点数/质心/范围），逐实体发布 `sel/cloud-box` |
| Esc | 清除选区/拾取 |
| 属性面板 | 颜色模式（逐点色/高度伪彩/单色）、投影、点大小、抽稀间隔、视角预设（等轴/前后左右上下）、重置视角 |

大点云（>500 万点）交互时自动抽稀到约 500 万点，鼠标静止 0.2s 后补画全量；信息栏显示「抽稀×N（交互）」。
可见点数超过视口像素数时进一步「密度封顶」（每像素至多 1 点），信息栏显示「抽稀×N（密度封顶）」，随窗口大小自动调整。
点云数据上传在后台线程执行（分块渐进显示），上传期间界面不卡顿；信息栏显示「上传中 N%」。

## 数据树（🌲 侧边栏）

- **2D 图像栏**：实时列出流水线发布的图像（无名发布归入「未命名图像」，有名=变量名/Id）。
- **栏目总开关（睁眼/闭眼）**：2D 图像、3D 点云标题行右侧的眼形开关——**闭眼=全部隐藏**（2D 清空工作台/3D 全部点云隐藏，记住之前的显示状态），**睁眼=恢复显示**。
- **2D 图像行交互**（与 3D 点云栏同款）：行首绿点=正在工作台显示（点击=把该图重新发送到工作台）；单击选中→下方「图像属性」（名字/尺寸/帧数/来源）+显示该图+跳转 2D 工作台；双击行名改名；Ctrl+C 复制 / Ctrl+V 粘贴副本（像素保留 ≤16MP）；Del 删除；Esc 取消选中。
- **3D 点云栏**：每行 = 一个点云实体（按总线 Id 区分，同 Id 重发=更新）：复选框显隐、删除按钮、点数/上传进度。
- **单击点云行**：详情区显示该点云的独立样式——**颜色模式 / 点大小**（只影响该实体）+ 尺寸/选区/来源；**同时跳转到 3D 点云工作台**。
- **单击 2D 图像行**：详情区显示图像属性，**同时显示该图并跳转到 2D 图像工作台**（行首绿点仍是显隐开关）。

- 每行 = 一个点云实体（按总线 Id 区分，同 Id 重发=更新）：复选框显隐、删除按钮、点数/上传进度。
- **单击行**：详情区显示该点云的独立样式——**颜色模式 / 点大小**（只影响该实体）+ 尺寸/选区/来源。
- 属性面板的全局颜色模式/点大小 = 批量应用到所有实体 + 新点云的默认值。

## 面板联动（总线约定主题）

| 主题 | 载荷 | 触发 |
|---|---|---|
| `image/stitched` | ImagePayload | 流水线发布图像 → 2D 面板 |
| `cloud/merged` | CloudPayload（含 Id） | 流水线发布点云 → 3D 面板增/改实体 |

**工作台数据源切换（2D/3D 都有）**：两个工作台工具栏各有「数据源」下拉，列出总线上有数据的对应类型主题（`cloud/*` / `image/*`），切换即退订旧主题、订阅新主题（3D 会清空当前实体再看新源（**锁定的实体保留**——数据树行右端锁徽标，与算法配方同款：绿开锁=未锁、灰闭锁=锁定；锁定的实体不可删除/改名，切源后仍在，解锁后恢复可删）；「2D 图像」栏的条目同样有锁徽标——锁定的图像不可删除/改名（同款图标与语义）。`cloud/removed`、`sel/*` 控制主题不受影响）。默认仍是约定主题 `cloud/merged` / `image/stitched`；下拉只列**总线上有数据**的主题——先让某条流水线往新主题发一次，它才会出现在列表里。配合「发布点云/发布图像」的主题参数，可把不同分支发到不同主题，工作台各选各的源。
| `cloud/removed` | CloudPayload（只需 Id） | 流水线「移除点云」算子 → 删除实体 |
| `sel/point3d` | SelectionPayload（xyz+uv） | 3D 拾取 → **2D 图像对应像素高亮十字标**（关联数据） |
| `sel/cloud-box` | SelectionPayload（Bounds3D） | 3D 框选 → 逐实体包围盒 |
| `sel/roi2d` | SelectionPayload（图像像素 xywh） | 2D 框选 ROI → 其他面板回显（洋红虚线） |

**总线监视**（🧩 面板列表里打开，窗口面板）：上半主题表（类型/帧数/频率/最后发布），**点击主题行** → 下半详细追踪——最新帧内容逐字段 + 发布历史（毫秒级时间戳，最多 100 条，可「清空历史」）。

## 常见问题

- **3D/2D 显示「无 GL 上下文」**：无 GPU 或驱动不支持 GL 3.3（2D 自动回退软件渲染）。
- **参数输入不生效**：数值参数需 **Enter / 失焦 / 点一下视口** 提交（输入过程不校验）。
- **新启动看不到 3D 参数**：3D 标签未激活时属性面板显示的是当前激活面板的参数——先点开对应标签。

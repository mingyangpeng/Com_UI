- 算子库同步流程（沉淀经验）：
  1. `git -C comdll/algo/alg fetch origin && merge --ff-only origin/main`
  2. `python tools/sync_alg.py sync --write` —— 只同步源码，**不同步 submodule 的 node.json**。
  3. 关键坑：新增算子时，submodule 的 `integration/comui/*.node.json`（权威声明）不会自动进运行时目录，backfill 因"已有标注跳过"也不会补新标注 → `gen check` 报"导出函数无标注"。
  4. 解法：先把 submodule 中新增/变更的 node.json 手动拷到 `comdll/algo/AlgProject/`，再 `backfill --write`（注入新标注）→ `gen --write` → `check`。
  5. 若已存在算子描述被改（如 filter_cloud/fit_model/voxel），backfill 会跳过其旧标注，导致 gen 把 node.json 写回旧描述；需先删除对应 cpp 标注块再 backfill 才会用新 node.json 重新注入。
  6. 最终校验：`check` = 94 标注 / 94 node.json / 0 错误（从 83 算子 → 94 算子）。

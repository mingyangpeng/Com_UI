## 算子库：C++ 标注生成 node.json 工具 + 文档修复

### 背景
用户确认 83 个 `*.node.json` 均为手工编写（git 作者 pengmingyang，11-13 提交 40 份、11-18 提交 45 份），仓库无生成工具。要求补上"从 C++ 源码生成 node.json"的工具，并修复文档 bug。

### 实现
- 新增 `tools/gen_node_json.py`（纯标准库，Python3）：
  - 标注格式：`integration/comui/*_comui.cpp` 导出函数正上方 `// @comui-node-begin ... // @comui-node-end` 包裹的 JSONC，含 node/inputs/params/outputs/source（+ 可选 file）。
  - 自动推导字段（标注里不写）：`runtime=native`、`assembly`（cpp 文件名去 `_comui.cpp` + `.dll`）、`method`（标注下方紧邻导出函数名）、文件名（id 去掉 `alg.`、点转下划线；例外用 `file` 覆盖，如 point3d_voxel）。
  - 三个子命令：`backfill`（从现有 node.json 反向注入标注，幂等）、`gen`（dry-run / `--write` 落盘）、`check`（标注↔node.json↔源文件引用三方校验，`--params` 附带参数 kind 宽松检查）。
  - 关键实现：strip_jsonc（剥离注释/尾逗号，字符串内安全）、BOM/CRLF 原样保留（cpp 为 UTF-8 BOM + CRLF）、固定字段顺序序列化。
- 用 backfill --write 给 3 个 cpp（Image2D/Point3D/Business）注入 83 个标注块。

### 验证（零回归）
- 内存 round-trip 83/83 完全一致；注入后 `check` = 标注 83 / node.json 83 / 错误 0 / 警告 0；`gen` dry-run = 一致 83 / 变更 0。
- 去掉标注块后 cpp 源码与备份逐字相同；BOM + 纯 CRLF 保留。
- `check --params` 有 11 条警告，均为已知误报（内联循环 / SickEntryLoad 委托读参，正则覆盖不全），非真实错位。

### 文档
- `docs/THIRD_PARTY_OPS.md:50`：修正过时描述「当前仅支持 dotnet（native 请包一层 C# 壳）」→「dotnet 或 native（见 §5）」。
- 新增 §1.1「从 C++ 标注生成 node.json（批量算子推荐）」：标注格式、自动推导字段、四个命令、新增算子标准流程。

## alg 源码改为 git submodule 引入 + 同步脚本

### 决策（用户拍板）
- 远程 `https://github.com/mingyangpeng/alg.git` 只提供源码；DLL 本地编译，不进子仓库；node.json 本地用脚本生成。
- 接入方式：submodule 放独立路径 `comdll/algo/alg`，运行时目录 `comdll/algo/AlgProject` 不动（宿主硬编码路径不变）。

### 关键事实
- 远程默认分支 `main`（早期误用 master 导致 zip 404）。仓库 ~194MB / 2.1 万文件，多数在 thrid/（第三方），不能整个拉。
- 远程 `integration/comui/*.cpp` 与本地**完全相同**（除本地的 @comui-node 标注）；远程 node.json 在 integration/comui/ 下、内容一致；远程**无 DLL**。
- 网络：SSH 无公钥；HTTPS 直连被 reset，走代理 127.0.0.1:7897 + `http.sslBackend=openssl` + `http.sslVerify=false` 才通（curl 需 --ssl-no-revoke）。git clone 大仓库反复 EOF，最终用 `--filter=blob:none --no-checkout` 只拉元数据成功。

### 实现
- submodule HEAD 1be8600，`.gitmodules` 配 `shallow=true` + `filter=blob:none`；submodule 内稀疏检出只留 src/ 与 integration/comui/（172 文件/7.3MB）。
- 新增 `tools/sync_alg.py`：`init`（no-checkout 注册→稀疏检出→checkout，避免下 2 万文件）、`status`（dry-run）、`sync --write`（拷源码→backfill 标注→gen 生成 node.json→check 校验）、`--skip-json`。
- 同步时剥离本地 cpp 标注再与远程比对，避免误判；标注由 backfill 从 node.json 恢复。
- `docs/THIRD_PARTY_OPS.md` 新增 §1.0 submodule 说明。
- 决策：保留主仓库对 AlgProject/src 的跟踪（不 git rm --cached），保证主仓库可独立 checkout，submodule 仅作更新源，同步后照常 commit 源码改动。

### 验证
- 同步 45 个源码文件→重建 node.json→check 83/83 零错误；再次 status 显示 0 差异（幂等）；init 重跑幂等；全量构建 0 错误。
